# Love Light Memories

開發一個[2026國際佛光會 世界會員代表大會]的活動網站
有兩個頁籤
一個是[活動內容]
一個是[拍貼機]

[活動內容]此頁放上圖檔：活動內容.png

[拍貼機]
會開啟[拍照模式]
可以選擇[圖框樣式]：
圖框01.png
圖框02.png

相機的畫面要出現在[圖框樣式]的中間正方形黑色區塊位置。

在預覽與成品輸出時加入對位微調（拖曳/滑桿），讓黑色區塊內的照片永遠完全居中且不被裁切。

請讓外框不要被中間的鏡頭蓋住，拍照後，將外框與鏡頭拍照的照片可以結合一張照片後可以預覽。

相機可以翻轉鏡頭
拍照完成後可以[預覽照片]，照片顯示在選擇[圖框樣式]的中間正方形黑色區塊位置。

可以
點選[儲存照片]按鈕：必須把預覽的照片成品(有外框以及有拍攝照片)下載到使用者手機。

點選[重新拍照]按鈕：回到[拍照模式]
